# ROADMAP

Часть идей уже реализована, остальное — планы. Статус актуализируется по мере работы.

## Сделано

1. **Кастомные профили пользователя** — «сохранить текущие флаги как профиль», применение и удаление в один клик, экспорт и импорт JSON-файлов.
2. **Автоподбор профиля по железу** — видеокарта и процессор определяются через WMI при первом запуске, рекомендация показывается на странице FastFlags с кнопками «Применить» и «Скрыть».
3. **Автоматические релизы** — пуш тега `v*` собирает Release-бинарник и публикует GitHub Release с готовым `SakuraTrap.exe`.
4. **Статистика сессий** — начало и конец сессии, число входов в игры записываются лаунчером и показываются в разделе «Интеграции».
5. **Тема «Sakura Night»** — тёмная тема с розовым акцентом сакуры для интерфейса.
6. **Планировщик профилей** — профиль применяется автоматически в заданные часы при каждом запуске Roblox.
7. **Полнота русской локализации** — заполнены все пустые строки `Strings.ru.resx`, удалены устаревшие ключи, новые фичи сразу двуязычные.

## Дальше

8. **Менеджер модов v2** — пресеты модов (курсоры + звуки + текстуры) как единый «пак», включение/выключение одним переключателем, совместимость с FastFlags-профилями.
9. **Проверка целостности клиента** — отчёт о том, какие файлы Roblox модифицированы модами, и восстановление оригинала в один клик.
10. **Профили под конкретные игры** — привязка профиля FastFlags к месту (placeId): в шутеры Performance, в визуальные новеллы Quality.
11. **Релизы с заметками** — автосборка уже есть, добавить ведение CHANGELOG и подпись артефактов.
