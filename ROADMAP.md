# ROADMAP

Часть идей уже реализована, остальное — планы. Статус актуализируется по мере работы.

## Сделано

1. **Кастомные профили пользователя** — «сохранить текущие флаги как профиль», применение и удаление в один клик, экспорт и импорт JSON-файлов.
2. **Автоподбор профиля по железу** — видеокарта и процессор определяются через WMI при первом запуске, рекомендация показывается на странице FastFlags с кнопками «Применить» и «Скрыть».
3. **Автоматические релизы** — пуш тега `v*` собирает Release-бинарник и публикует GitHub Release с готовым `SakuraTrap.exe`.
4. **Статистика сессий** — начало и конец сессии, число входов в игры записываются лаунчером и показываются в разделе «Интеграции».
5. **Тема «Sakura Night»** — тёмная тема с розовым акцентом сакуры для интерфейса.
6. **Планировщик профилей** — профиль применяется автоматически в заданные часы при каждом запуске Roblox.
7. **Полнота русской локализации** — заполнены все пустые строки `Strings.ru.resx`, удалены устаревшие ключи, новые фичи сразу двуязычные.
8. **Переключатель профилей из трея** — подменю у иконки в трее: Default/Balanced/Performance/Quality плюс свои профили, галочка на активном, подтверждение шаром-уведомлением; действует со следующего запуска Roblox.
9. **Проверка обновлений** — раз в сутки лаунчер смотрит последний релиз на GitHub и показывает InfoBar в настройках со ссылкой на страницу релиза (без автоподмены файлов).
10. **Недельная сводка статистики** — в «Интеграциях» появились последние 7 дней: часы в игре и число сессий по дням с мини-диаграммой.
11. **Менеджер модов v2 (паки)** — установленные моды собираются в именованные паки (`Modifications\Packs`), включение/выключение одним переключателем; хранилище паков исключено из автоприменения, с FastFlags-профилями не пересекается.
12. **Проверка целостности клиента** — отчёт по каждому применённому моду (применён / отличается / отсутствует) и восстановление оригиналов в один клик: файлы удаляются, оригиналы докачиваются из пакетов Roblox при следующем запуске.
13. **Новая иконка** — чистая сакура с прозрачным фоном (снята обработкой чёрного фона), многослойный `.ico` 16–256 px вместо шакальной старой.
14. **Обновление в один клик** — InfoBar обновлений теперь сам скачивает релиз с GitHub (с процентами) и запускает установщик в режиме авто-апгрейда.
15. **Резервная копия конфига** — экспорт/импорт всего в один ZIP: настройки, профили флагов, паки модов с файлами, свои темы, статистика; куки не включаются, после импорта — автоперезапуск.
16. **Паки: развитие** — раскрывающийся список файлов пака, «добавить текущие моды в пак», переименование пака.
17. **Автопроверка целостности** — при старте лаунчера тихо проверяется клиент; если файлы изменены вне мод-системы — InfoBar с переходом на страницу модов.
18. **Хранение старых версий Roblox** — настройка «сколько предыдущих версий хранить» (0–2) на странице развёртывания.
19. **Оформление v2** — свой акцентный цвет (hex + превью-свотч), светлая тема Sakura Light, режим «сакура по времени суток» (днём светлая, ночью тёмная), градиент и тултипы на недельном графике, падающие лепестки в «О программе».
