# ROADMAP

Идеи развития SakuraTrap — от ближайших к далёким. Часть пунктов требует обсуждения механики, поэтому каждый помечен статусом.

## Ближайшие шаги

1. **Кастомные профили пользователя** — кнопка «сохранить текущий набор флагов как профиль»: клиент сам соберёт профиль из своего `ClientAppSettings.json`, профили можно будет экспортировать и импортировать JSON-файлом и делиться ссылкой.
2. **Автоподбор профиля по железу** — при первом запуске определить GPU/CPU через WMI и предложить подходящий профиль: слабым машинам Performance, топовым Quality, остальным Balanced.
3. **Автоматические релизы** — пуш тега `v*` собирает Release-бинарник и публикует GitHub Release с готовым `SakuraTrap.exe`, чтобы README-ссылка «Download» работала без ручных действий.

## Средняя перспектива

4. **Статистика сессии** — после выхода из игры показывать сводку (время сессии, версия клиента, применённые флаги) на основе логов, которые Roblox уже пишет в `%APPDATA%`; без оверлея и внедрения в процесс.
5. **Темы оформления** — тёмно-розевая «Sakura Night» тема для интерфейса настроек и bootstrapper-диалогов, сезонные вариации иконки.
6. **Планировщик профилей** — автоматическое переключение профиля по времени суток или по запускаемому приложению (например, ночью — тихий и энергоэффективный набор флагов).
7. **Полнота русской локализации** — вычитать и дополнить `Strings.ru.resx` (часть строк в апстриме пустая), синхронизировать новые ключи.

## Далёкие идеи

8. **Менеджер модов v2** — пресеты модов (курсоры + звуки + текстуры) как единый «пак», включение/выключение одним переключателем, совместимость с FastFlags-профилями.
9. **Проверка целостности клиента** — отчёт о том, какие файлы Roblox модифицированы модами, и восстановление оригинала в один клик.
10. **Профили под конкретные игры** — привязка профиля FastFlags к месту (placeId): в шутеры Performance, в визуальные новеллы Quality.
